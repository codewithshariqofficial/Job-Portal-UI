## About

A **modern job portal UI** with job listings, search filters, job details and application forms. Clean professional design suitable for job boards and career platforms.

Built with **vanilla HTML, CSS, and JavaScript**.

---

## Features

| Feature | Description |
|---------|-------------|
| Job Listings | Browse available jobs |
| Search Filter | Find jobs by keyword |
| Job Details | Full job description |
| Apply Form | Job application form |
| Company Cards | Company info display |
| Responsive | Works on all devices |
| Clean UI | Professional design |
| Smooth Navigation | Easy page navigation |
